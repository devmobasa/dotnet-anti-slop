# DAS3003: Pass CancellationToken to EF Core async queries

**Category:** EF Core

**Default severity:** warning
**Signal confidence:** high

## Rule

Supply the current token to EF Core asynchronous terminal operators.

## Why

Database commands can continue consuming a connection and server resources after the caller has gone away.

## Noncompliant

```csharp
await query.ToListAsync();
```

## Compliant

```csharp
await query.ToListAsync(cancellationToken);
```

## Detection

Reports resolved EF Core async query operators whose cancellation argument is omitted in async code.

## Boundaries

Provider support for cancellation varies, but propagation is still the correct application contract.

## Configuration

```ini
[*.cs]
dotnet_diagnostic.DAS3003.severity = warning
```

Use `none` only after replacing the policy with an equivalent architectural or
test-enforced control. Prefer a line- or member-level suppression for a
documented exception.
