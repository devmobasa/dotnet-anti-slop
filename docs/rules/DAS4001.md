# DAS4001: Asynchronous tests must return Task

**Category:** Testing

**Default severity:** error
**Signal confidence:** high

## Rule

Use Task or ValueTask for asynchronous test methods; never async void.

## Why

Test runners cannot reliably await async void tests or associate later exceptions with the correct test.

## Noncompliant

```csharp
[Fact] public async void Saves_order() { await Sut.SaveAsync(); }
```

## Compliant

```csharp
[Fact] public async Task Saves_order() { await Sut.SaveAsync(); }
```

## Detection

Recognizes xUnit, NUnit, and MSTest attributes semantically and reports async test methods returning `void`.

## Boundaries

Non-standard test frameworks may require an additional recognized attribute mapping.

## Configuration

```ini
[*.cs]
dotnet_diagnostic.DAS4001.severity = error
```

Use `none` only after replacing the policy with an equivalent architectural or
test-enforced control. Prefer a line- or member-level suppression for a
documented exception.
