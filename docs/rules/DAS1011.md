# DAS1011: Consume a ValueTask only once

**Category:** Async

**Default severity:** error
**Signal confidence:** high

## Rule

Await a ValueTask once, or convert it to a Task once when repeated consumption is required.

## Why

A ValueTask may wrap an IValueTaskSource and is not generally safe to await, inspect, or convert multiple times.

## Noncompliant

```csharp
await pending; await pending;
```

## Compliant

```csharp
var task = pending.AsTask(); await task; await task;
```

## Detection

Tracks local/parameter `ValueTask` symbols and reports the second await, `AsTask`, `GetAwaiter`, or `Result` consumption.

## Boundaries

A `ValueTask` known to wrap a `Task` may tolerate repeated awaits, but callers should not depend on that implementation detail.

## Configuration

```ini
[*.cs]
dotnet_diagnostic.DAS1011.severity = error
```

Use `none` only after replacing the policy with an equivalent architectural or
test-enforced control. Prefer a line- or member-level suppression for a
documented exception.
