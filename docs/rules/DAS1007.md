# DAS1007: Use Any for an existence check

**Category:** LINQ

**Default severity:** warning
**Signal confidence:** high

## Rule

Do not enumerate a LINQ sequence with Count or LongCount only to compare the result with zero.

## Why

Any can stop at the first element and translates to an existence query for LINQ providers.

## Noncompliant

```csharp
if (orders.Count() > 0) { /* ... */ }
```

## Compliant

```csharp
if (orders.Any()) { /* ... */ }
```

## Detection

Reports resolved `System.Linq` `Count()`/`LongCount()` calls compared with numeric zero. Collection `Count` properties are ignored.

## Boundaries

An exact count is different from existence. Use `Count` when the number is actually needed.

## Configuration

```ini
[*.cs]
dotnet_diagnostic.DAS1007.severity = warning
```

Use `none` only after replacing the policy with an equivalent architectural or
test-enforced control. Prefer a line- or member-level suppression for a
documented exception.
