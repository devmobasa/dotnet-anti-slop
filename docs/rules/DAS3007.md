# DAS3007: Parameterize raw SQL

**Category:** EF Core

**Default severity:** error
**Signal confidence:** high

## Rule

Use interpolated EF APIs or explicit parameters rather than composing user or variable data into Raw SQL APIs.

## Why

Dynamic text passed to Raw APIs can change SQL structure and introduce injection vulnerabilities.

## Noncompliant

```csharp
db.Orders.FromSqlRaw($"SELECT * FROM Orders WHERE Name = '{name}'");
```

## Compliant

```csharp
db.Orders.FromSqlInterpolated($"SELECT * FROM Orders WHERE Name = {name}");
```

## Detection

Finds the SQL string parameter of EF Raw APIs and allows compile-time constants; dynamic, concatenated, and interpolated expressions are reported.

## Boundaries

Compile-time constant SQL with explicit parameters is allowed. The rule cannot prove that stored procedures or database permissions are safe.

## Configuration

```ini
[*.cs]
dotnet_diagnostic.DAS3007.severity = error
```

Use `none` only after replacing the policy with an equivalent architectural or
test-enforced control. Prefer a line- or member-level suppression for a
documented exception.
