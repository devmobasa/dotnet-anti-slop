# DAS1009: Set collection capacity when the size is knowable

**Category:** Collections

**Default severity:** suggestion
**Signal confidence:** medium

## Rule

Provide an initial capacity when a collection is populated from a source with a known count.

## Why

Capacity hints avoid repeated array growth, copying, and temporary allocations.

## Noncompliant

```csharp
var result = new List<Order>(); foreach (var order in orders) result.Add(Map(order));
```

## Compliant

```csharp
var result = new List<Order>(orders.Count); foreach (var order in orders) result.Add(Map(order));
```

## Detection

Reports zero-capacity generic collections followed by a known-size `for`/`foreach` loop that adds to that collection.

## Boundaries

A capacity hint is useful only when the source count is trustworthy and the destination will retain most items.

## Configuration

```ini
[*.cs]
dotnet_diagnostic.DAS1009.severity = suggestion
```

Use `none` only after replacing the policy with an equivalent architectural or
test-enforced control. Prefer a line- or member-level suppression for a
documented exception.
