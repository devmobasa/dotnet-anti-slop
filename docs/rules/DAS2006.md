# DAS2006: Guard development-only middleware

**Category:** ASP.NET Core

**Default severity:** warning
**Signal confidence:** medium

## Rule

Place developer exception pages, migration endpoints, and interactive API UI behind an environment or explicit security guard.

## Why

Development diagnostics can expose implementation details and unnecessarily expand a production attack surface.

## Noncompliant

```csharp
app.UseDeveloperExceptionPage(); app.UseSwaggerUI();
```

## Compliant

```csharp
if (app.Environment.IsDevelopment()) { app.UseDeveloperExceptionPage(); app.UseSwaggerUI(); }
```

## Detection

Recognizes selected Microsoft development middleware and both positive development blocks and negated early-exit guards.

## Boundaries

Production Swagger can be valid when deliberately authenticated and authorized; document and suppress that exact call.

## Configuration

```ini
[*.cs]
dotnet_diagnostic.DAS2006.severity = warning
```

Use `none` only after replacing the policy with an equivalent architectural or
test-enforced control. Prefer a line- or member-level suppression for a
documented exception.
