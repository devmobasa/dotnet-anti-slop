# DAS3009: Use AnyAsync for existence checks

**Category:** EF Core

**Default severity:** warning
**Signal confidence:** high

## Rule

Use AnyAsync rather than comparing CountAsync with zero.

## Why

An existence query can stop when a match is found and normally translates to EXISTS.

## Noncompliant

```csharp
if (await db.Orders.CountAsync(ct) > 0) { /* ... */ }
```

## Compliant

```csharp
if (await db.Orders.AnyAsync(ct)) { /* ... */ }
```

## Detection

Reports EF Core `CountAsync` when the awaited/result expression is compared with numeric zero.

## Boundaries

Use `CountAsync` when the exact count is returned or used in later arithmetic.

## Configuration

```ini
[*.cs]
dotnet_diagnostic.DAS3009.severity = warning
```

Use `none` only after replacing the policy with an equivalent architectural or
test-enforced control. Prefer a line- or member-level suppression for a
documented exception.
