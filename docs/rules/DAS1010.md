# DAS1010: Avoid boxing in hot loops

**Category:** Performance

**Default severity:** warning
**Signal confidence:** high

## Rule

Keep value types on generic or strongly typed paths inside loops.

## Why

Converting a value type to object or an interface can allocate a boxed copy on the managed heap.

## Noncompliant

```csharp
foreach (var value in values) nonGenericList.Add(value);
```

## Compliant

```csharp
foreach (var value in values) genericList.Add(value);
```

## Detection

Uses the compiler conversion classification to report actual boxing conversions in loop arguments.

## Boundaries

The rule is loop-scoped. Boxing outside a hot path can be harmless and may improve API clarity.

## Configuration

```ini
[*.cs]
dotnet_diagnostic.DAS1010.severity = warning
```

Use `none` only after replacing the policy with an equivalent architectural or
test-enforced control. Prefer a line- or member-level suppression for a
documented exception.
