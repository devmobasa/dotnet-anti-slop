# DAS1004: Forward the available CancellationToken

**Category:** Async

**Default severity:** warning
**Signal confidence:** high

## Rule

Pass the current operation's token to cancellable asynchronous calls.

## Why

Dropping a token lets downstream I/O continue after a request, job, or caller has been cancelled.

## Noncompliant

```csharp
await stream.CopyToAsync(destination);
```

## Compliant

```csharp
await stream.CopyToAsync(destination, cancellationToken);
```

## Detection

Looks for an in-scope `CancellationToken` and an omitted token argument or compatible cancellable overload. EF Core terminals are owned by DAS3003/DAS3004.

## Boundaries

Cross-assembly overload discovery is conservative. Dynamic invocation and custom awaitables may not be recognized.

## Configuration

```ini
[*.cs]
dotnet_diagnostic.DAS1004.severity = warning
```

Use `none` only after replacing the policy with an equivalent architectural or
test-enforced control. Prefer a line- or member-level suppression for a
documented exception.
