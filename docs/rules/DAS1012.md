# DAS1012: Bound asynchronous fan-out

**Category:** Concurrency

**Default severity:** warning
**Signal confidence:** medium

## Rule

Do not feed an unbounded projection directly into Task.WhenAll.

## Why

Starting one operation per input can exhaust sockets, database pools, memory, or downstream rate limits.

## Noncompliant

```csharp
await Task.WhenAll(ids.Select(id => LoadAsync(id, cancellationToken)));
```

## Compliant

```csharp
await Parallel.ForEachAsync(ids, new ParallelOptions { MaxDegreeOfParallelism = 16, CancellationToken = cancellationToken }, LoadAsync);
```

## Detection

Reports `Task.WhenAll(sequence.Select(...))` when the projection has no visible `Take` bound.

## Boundaries

Small, trusted collections may be safe. Prefer an explicit bound or a narrow suppression with workload evidence.

## Configuration

```ini
[*.cs]
dotnet_diagnostic.DAS1012.severity = warning
```

Use `none` only after replacing the policy with an equivalent architectural or
test-enforced control. Prefer a line- or member-level suppression for a
documented exception.
