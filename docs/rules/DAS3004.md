# DAS3004: Pass CancellationToken to SaveChangesAsync

**Category:** EF Core

**Default severity:** warning
**Signal confidence:** high

## Rule

Supply the current token when persisting changes.

## Why

SaveChangesAsync may perform multiple database commands and should participate in request or job cancellation.

## Noncompliant

```csharp
await db.SaveChangesAsync();
```

## Compliant

```csharp
await db.SaveChangesAsync(cancellationToken);
```

## Detection

Reports `DbContext.SaveChangesAsync` when the cancellation argument is omitted in async code.

## Boundaries

A transaction may need a non-cancellable commit phase after a point of no return. Isolate and explain that phase.

## Configuration

```ini
[*.cs]
dotnet_diagnostic.DAS3004.severity = warning
```

Use `none` only after replacing the policy with an equivalent architectural or
test-enforced control. Prefer a line- or member-level suppression for a
documented exception.
