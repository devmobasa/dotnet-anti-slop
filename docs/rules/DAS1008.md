# DAS1008: Avoid repeated enumeration of a lazy sequence

**Category:** LINQ

**Default severity:** warning
**Signal confidence:** medium

## Rule

Materialize once or restructure the operation when the same lazy sequence is enumerated repeatedly.

## Why

Repeated enumeration can repeat expensive work, consume one-shot iterators, or execute a database query more than once.

## Noncompliant

```csharp
if (orders.Any()) return orders.ToList();
```

## Compliant

```csharp
var materialized = orders.ToList(); if (materialized.Count != 0) return materialized;
```

## Detection

Within a callable, tracks repeated terminal operations or `foreach` over the same local/parameter when its static type is lazy and not a materialized collection.

## Boundaries

The analysis is local and identifier-based. Aliasing, helper methods, and custom memoizing iterators are not modeled.

## Configuration

```ini
[*.cs]
dotnet_diagnostic.DAS1008.severity = warning
```

Use `none` only after replacing the policy with an equivalent architectural or
test-enforced control. Prefer a line- or member-level suppression for a
documented exception.
