# DAS1006: Avoid string accumulation in loops

**Category:** Performance

**Default severity:** warning
**Signal confidence:** high

## Rule

Use StringBuilder, a buffer, string.Create, or a single join operation for repeated concatenation.

## Why

Strings are immutable. Repeated accumulation copies the growing string and creates many temporary objects.

## Noncompliant

```csharp
foreach (var item in items) text += item.Name;
```

## Compliant

```csharp
var builder = new StringBuilder(capacity); foreach (var item in items) builder.Append(item.Name);
```

## Detection

Reports string `+=`, self-concatenation, and self-interpolation assignments only beneath a loop.

## Boundaries

The compiler already optimizes fixed, non-loop concatenation. This rule intentionally does not report ordinary one-expression interpolation.

## Configuration

```ini
[*.cs]
dotnet_diagnostic.DAS1006.severity = warning
```

Use `none` only after replacing the policy with an equivalent architectural or
test-enforced control. Prefer a line- or member-level suppression for a
documented exception.
